# 开发说明

> 玩家只需要看根目录的 [README.md](../README.md)，从 Releases 下载就能玩。本文面向开发者，完整设计文档见 [docs/README.md](README.md)：包括难度表、角色等级、语音台词、平衡性模拟、架构图和换皮说明。

## 技术栈

HTML5 Canvas 2D · 原生 JavaScript（ES Modules）· Matter.js 0.19 · esbuild · Electron · Playwright · WebAudio（实时合成音效）· AivisSpeech（离线生成角色语音）· Python（程序化作曲 BGM）

## 运行与构建

```bash
npm install
npm start              # 构建，并在 http://localhost:8765 启动开发服务器
npm run build          # 构建到 dist/（构建结果可以直接双击 dist/index.html，也就是网页版发布包的内容）
npm run desktop        # 用 Electron 运行桌面版
npm run package:win    # 打包 Windows x64，输出到 release/美少女合成/（exe 版本信息：公司 狸猫，含 licenses/）
npm run package:linux  # 打包 Linux x64，输出到 build/linux-x64/（用于桌面版自动化测试）
node tools/bot-sim.mjs # 难度平衡模拟（需要先 build）
```

## 测试

```bash
npx playwright install chromium            # 首次需要
npm run build && npm test                  # 浏览器版自动化测试
xvfb-run -a npm run test:audit             # 逻辑审计回归测试（固定随机种子，可复现）
npm run test:ads                           # 出品署名、网页版无广告入口
npm run package:linux && xvfb-run -a npm run test:desktop   # 桌面版（Electron）
npm run build:douyin && npm run test:douyin # 抖音小游戏（模拟 tt 环境）
npm run build:wechat && npm run test:wechat # 微信小游戏（模拟 wx 环境）
```

## 发布 GitHub Release

Releases 页面提供以下两个文件：

- `meishaonv-hecheng-windows.zip`：内容是 `美少女合成/`（即 `npm run package:win` 生成的 `release/美少女合成/`）和 `怎么玩.txt`。
- `meishaonv-hecheng-web.zip`：内容是 `美少女合成-网页版/`（即 `npm run build` 生成的 `dist/`）和 `怎么玩.txt`。

压缩时文件名要使用 UTF-8 编码标记（Python `zipfile` 会自动设置）。这样 Windows 资源管理器和 `Expand-Archive` 解压时，中文文件夹名才能正确显示。

网页版和桌面版都不显示任何广告，也没有看广告入口（`PlatformConfig.web.placeholderAds` / `desktop.placeholderAds` 均为 `false`）。相关配置在 `src/config/PlatformConfig.js` 中。

## 平台抽象层

`src/platform/` 下的平台类：`Platform`（接口）→ `WebPlatform` / `ElectronPlatform` / `DouyinPlatform` → `WechatPlatform`。

- 画布、输入、图片、音频、存储、前后台切换、广告和分享，全部都经过平台层。
- 游戏逻辑里不出现 `window`、`document`、`tt` 或 `wx`。小游戏构建时会做静态检查。
- 入口文件：`src/main.js`（网页版和桌面版）、`src/main.douyin.js`、`src/main.wechat.js`。

## 小游戏工程（目前暂停发布，代码保留）

仓库中保留了两个可以直接导入开发者工具的小游戏工程。目前的发行渠道是 GitHub Releases，暂时不在抖音或微信上架。

| | 抖音小游戏 | 微信小游戏 |
| --- | --- | --- |
| 工程目录 | `douyin/`（`npm run build:douyin`） | `wechat/`（`npm run build:wechat`） |
| 配置 | `src/config/PlatformConfig.js` 的 `douyin` 段 | 同一文件的 `wechat` 段（AppID `wx6def2bda0bd75e11`） |
| 上架说明 | [`douyin/抖音上架说明.md`](../douyin/抖音上架说明.md)，资料在 `docs/douyin/` | [`docs/微信上架说明.md`](微信上架说明.md)，资料在 `docs/wechat/` |
| 包体 | 主包约 1.0 MB，整体约 2.4 MB | 主包约 1.1 MB，整体约 2.5 MB |

两个版本共同的处理：

- 音频只使用 mp3 和 wav，因为 iOS 不支持 ogg。
- BGM 由两个播放器在循环点交叉淡化，实现无缝循环。
- 没有填写广告位 ID 时，隐藏所有看广告按钮，改为每局 1 次免费「再试一次」。

两个版本的区别：

- 抖音版：自动录屏分享，有侧边栏复访奖励。
- 微信版：用「分享给好友」和右上角菜单转发，也可以分享到朋友圈。
