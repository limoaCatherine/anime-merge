## 1. 注册小游戏账号 📱

1. 打开 <https://mp.weixin.qq.com/> → 右上角「**立即注册**」→ 选「**小程序**」。
   - 小游戏是小程序的一个类目，**注册时选小程序**，第 4 步选「游戏」类目后，这个账号就成为小游戏。
2. 填写邮箱（这个邮箱**没有注册过**公众号、小程序或开放平台）和密码 → 到邮箱点激活链接。
3. **主体信息登记**：主体类型选「**企业**」，填写营业执照上的**公司全称**和统一社会信用代码，再填写管理员的姓名、身份证号和手机号。
   - 📱 **管理员用自己的手机微信扫码**做身份验证（这个微信必须绑定了管理员本人的银行卡）。
   - ⚠ 主体就是软著、隐私政策和备案里使用的**真实公司**。「狸猫」只是出品品牌，不能用作主体名称。
4. 登录后在首页「**小程序信息**」中填写：
   - 名称：`美少女合成`（全网唯一，被占用时需要换名）。
   - 头像：用 `上架资料/screenshots/游戏图标_512x512_无圆角.png`。
   - 介绍：见 `上架资料/商店文案.md`。
   - **服务类目**：「游戏」→「休闲游戏」。
   - ⚠ 名称、主体在提交小游戏备案后就不能修改，务必一次定好。

官方：[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide)、[发布流程中的「注册小游戏账号」](https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release.html)

## 2. 微信认证（企业主体必做）📱

- 入口：MP 后台 → 设置 → 微信认证。按页面提交企业资料，并支付审核服务费（金额以页面为准）。
- 📱 管理员需要用手机微信扫码确认。
- 企业主体**必须先完成微信认证**，才能提交小程序备案。

## 3. 获取 AppID

> ✅ 已完成：本作 AppID 为 **`wx6def2bda0bd75e11`**，已填入 `src/config/PlatformConfig.js`（`wechat.appId`）和 `wechat/project.config.json`。下面的步骤留作参考，例如以后换账号时使用。

1. MP 后台 → 「开发」→「开发管理」→「开发设置」，复制 **AppID(小程序ID)**（`wx` 开头）。
2. 打开源码中的 `src/config/PlatformConfig.js`，把 `wechat.appId` 改为这个 AppID，然后运行：
   ```
   npm run build:wechat
   ```
   - 不改也可以：直接在开发者工具「详情 → 基本信息 → AppID」里修改。
   - 如果 AppID 还是 TODO，构建会写入占位值 `touristappid`（游客模式）。游客模式只能在模拟器里运行，不能真机预览，也不能上传。

## 4. 安装微信开发者工具 📱

- 下载「稳定版」：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>（Windows 64 位）。
- 打开后 📱 **用手机微信扫码登录**。这个微信号必须是本小游戏的**管理员或开发者**；添加开发者的位置是 MP 后台「管理 → 成员管理」。

## 5. 导入工程

1. 开发者工具 →「导入项目」→ 目录选 `美少女合成\微信小游戏`（也就是构建输出的 `wechat/` 文件夹）。
2. AppID 会自动读取 `wx6def2bda0bd75e11`。工具会识别出 `compileType: game`，也就是小游戏工程。
3. 模拟器里应该依次看到：加载页（健康游戏忠告、出品：狸猫、适龄提示 8+，同时下载语音和音乐分包），然后进入主菜单。
4. 右上角「详情 → 基本信息」可以看到包体：主包约 1.1 MB，`media` 分包约 1.4 MB。

## 6. 真机预览 📱

- 点工具栏「**预览**」，然后 📱 用手机微信扫码，在真机上试玩。
- 也可以点「真机调试」查看日志。
- 重点检查：
  - iPhone 有没有声音。如果开了静音键，iOS 默认不出声，可以在设置面板里调大音量。
  - 背景音乐循环时有没有断点。
  - 右上角胶囊按钮有没有挡住 HUD。
  - 右上角「···」菜单里是否有「转发给朋友」，安卓上是否有「分享到朋友圈」。
  - 结算页的「分享给好友」按钮能否拉起转发。

## 7. 上传代码

### 方式 A：开发者工具（推荐）
- 点工具栏「**上传**」。版本号填 `1.8.0`，备注写本次更新内容。
- 上传后，在 MP 后台「管理 → 版本管理」的「开发版本」里可以看到这次上传。
- 可以把它设为「**体验版**」，再到「成员管理 → 体验成员」添加体验者。📱 体验者扫码体验。

### 方式 B（可选）：miniprogram-ci 命令行上传
1. 📱 管理员登录 MP 后台 →「管理 → 开发管理 → 开发设置 → 小程序代码上传」，生成并下载「**代码上传密钥**」（`private.wx….key`），然后配置 **IP 白名单**。
   - 没有配置 IP 白名单就无法上传。
   - 密钥丢失只能重置。
   - **不要把密钥放进项目或提交到 GitHub**。项目的 .gitignore 已经忽略 `*.key`。
2. 在项目根目录执行：
   ```
   npm install -g miniprogram-ci
   miniprogram-ci upload --pp ./wechat --pkp D:\keys\private.wxXXXXXXXX.key --appid wxXXXXXXXX --uv 1.8.0 -r 1 --enable-es6 true
   ```
   - `--pp` 是 project.config.json 所在的目录。
   - 用 Node 脚本调用时，`type` 要写 `'miniGame'`。
3. 官方：[miniprogram-ci 介绍](https://developers.weixin.qq.com/minigame/dev/devtools/ci.html)

## 8. 设置适龄提示（在资质审核之前）

- MP 后台 → 设置 → 基础设置 → 基本信息 → **适龄提示**，选 **8+**，然后提交审核。
- 8+ 的参考标准：画面是卡通、手绘风格，没有复杂剧情，对抗内容不写实，也没有陌生人社交。
- ⚠ 必须和游戏内一致。游戏启动页显示的是 `PlatformConfig.wechat.ageRating`（默认 `'8+'`）。如果后台改了，这里也要改，然后重新构建。
- 官方：[适龄提示设置指引](https://developers.weixin.qq.com/minigame/introduction/guide/slts.html)

## 9. 用户隐私保护指引

- MP 后台 → 设置 → 服务内容声明（基本设置）→ **用户隐私保护指引**。
- 本作只用到这些接口：画布、触摸、音频、本地缓存、激励广告和转发。没有调用官方列表中任何涉及个人信息的 API，比如 getUserInfo、位置、关系链（好友排行榜）、剪贴板、相册和麦克风。所以这里选「**确认承诺未处理用户任何信息**」即可，后续步骤都不用做。
- 以后如果加了好友排行榜（关系链）或者获取头像昵称，就必须更新隐私指引，并在调用相关接口前弹出隐私授权（`wx.onNeedPrivacyAuthorization` / `wx.requirePrivacyAuthorize`）。
- 游戏内的隐私政策文本可以参考 `上架资料/隐私协议草稿.md`，**主体要写真实公司全称**。
- 官方：[小游戏隐私合规开发指南](https://developers.weixin.qq.com/minigame/introduction/guide/privacy)

## 10. 资质审核（IAA：情况二）

1. 入口：MP 首页 →「小程序备案 → 小游戏备案&发布流程指引 → 资质提交」，或者「设置 → 游戏设置 → 资质管理 → 前往管理」。
2. 选择游戏情况：**情况二：小游戏当前及未来均不需要开通虚拟支付**。
3. 类目选和内容一致的游戏**三级类目**，比如休闲类下的合成或益智类，以后台列表为准。支付资质选「**不申请支付资质**」。
4. 上传材料。需要软著或授权材料时，按模块对应上传，**不要传错位置**。常见被驳回的原因：
   - 名称或主体不一致。
   - 盖了合同章、财务章或电子章。
   - 签名不规范。
   - 签署日期不完整。
5. 办结时限一般为 1–3 个自然日。
- 官方：[资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)

## 11. 提交版本审核

1. MP 后台 → 管理 → 版本管理 → 开发版本 →「**提交审核**」。
2. 按提示完善「**游戏内容介绍**」：
   - 玩法说明、功能介绍。
   - 截图：用 `上架资料/screenshots/` 中的 1080×1920 竖屏截图，都是**微信版实拍**（结算页是「分享给好友」，没有抖音侧边栏）。
3. 必填项：
   - 「**游戏自审自查报告**」：在提审页面下载官方模板，按实际情况填写，企业主体**加盖公章**后扫描或拍照上传。
   - 「**版本更新说明**」：例如「首个版本：美少女合成小游戏，支持三档难度、角色语音、转发好友」。
4. 游戏引擎一栏选「其他」，填写「自研（HTML5 Canvas + Matter.js）」。
5. 审核通过后会收到「微信 → 服务通知」。
- 官方：[发布流程（官方说明）](https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release.html)、[运营规范](https://developers.weixin.qq.com/minigame/product/)

## 12. 角色语音授权（提审前必读）

`docs/licenses/角色权利方指南-复核-2026-10-11.md` 的结论是：11 句角色语音中有 **8 句** 来自コハク / まお（Trippy）、凛音エル（BOOTH 规约）、みちのくあいり / らせつん（こずかた）。这些权利方要求**企业或商用先联系他们取得许可**。

- 微信 IAA 资质审核中写明：「涉及相关品牌、公众人物合作」时需要提交授权材料。
- **建议上架前取得书面许可，或者换成无需联系的声音**（リダ、黄金笑等）。

## 13. 小游戏备案 → 小程序备案

1. **小游戏备案**：入口是「账号设置 → 小程序备案 → 去完善 → 小游戏备案 → 前往提交」，选「**情况二**」。
   - 前提：适龄提示已经设置好。
   - 审批时长：平台 1–2 天，主管部门 10–20 个工作日。
   - 提交后**不能再改名称或主体**。
   - 官方：[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)
2. **小程序备案**：在小游戏备案通过后进行。流程如下：
   1. 填写备案信息，需要主体负责人和小程序负责人的证件。📱 负责人可能需要扫码做人脸核验。
   2. 平台初审。
   3. **工信部短信核验**：初审通过后，负责人手机会收到 12381 短信，需要在 **24 小时内**登录 <https://beian.miit.gov.cn/> 完成核验。
   4. 通管局审核。
   - 官方：[小程序备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html)

## 14. 发布 📱

- 版本审核和备案**都通过后**，打开「版本管理 → 审核版本 → **提交发布**」，选择全量发布。📱 管理员需要扫码确认。
- 发布后可以在手机微信里搜索「美少女合成」。

## 15. 上线后：开通流量主与激励广告

1. 满足开通条件（例如累计 UV > 500）后的**第二天**，在 MP 后台「功能 → 流量主」开通，并补充结算资料。
2. 进入「流量主 → 广告管理」，新建「**激励广告**」，得到 `adunit-xxxxxxxx`。
3. 把它填进 `src/config/PlatformConfig.js` 的 `wechat.rewardedAdUnitId`，然后执行 `npm run build:wechat`，重新上传并提审。
4. 广告位的行为：
   - **没填广告位**（首发版本就是这样）：所有「看视频」按钮都隐藏，每局有 1 次免费「再试一次」（复活），整理次数用完就没有了。
   - **填了广告位之后**：复活变成「▶ 看视频复活」（每局 1 次）；整理次数用完后，可以看视频再加 1 次（每局 1 次）。只有视频**看完**（`onClose` 返回 `res.isEnded === true`）才发放奖励。
- 官方：[广告开通条件](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/ad.html)、[激励视频广告](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/rewarded-video-ad.html)、[RewardedVideoAd](https://developers.weixin.qq.com/minigame/dev/api/ad/RewardedVideoAd.html)
